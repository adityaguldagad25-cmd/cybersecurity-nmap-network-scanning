# Nmap Network Scanning Project

## About
This project demonstrates basic network scanning using Nmap on Kali Linux.

## Objectives
- Understand basic Nmap scanning.
- Scan localhost (127.0.0.1).
- Identify the state of TCP ports.
- Save scan results to a text file.

## Tools Used
- Kali Linux
- Nmap 7.99

## Scan Performed
```bash
nmap 127.0.0.1
```

## Results
- Target: 127.0.0.1 (localhost)
- Host status: Up
- Ports scanned: 1000 TCP ports
- Open ports found: 0
- Closed ports: 1000

## Conclusion
The localhost scan completed successfully. All 1000 scanned TCP ports were closed at the time of the scan.

## Disclaimer
This project was performed on my own local system for educational purposes.
